Hospital Queue Management Protocol

  • Sequential Calling: Patients are called strictly by sequence order (FIFO) within each clinic queue.
  • Single Serving Constraint: Only one patient token can be active in consultation at this station. Complete or mark no-show before calling the next patient.
  • No-Show Management: If an announced patient does not appear after calling, use Mark No-Show to immediately release the window.
